# Finder Social v2

Локальный прототип подросткового сообщества: регистрация/вход, анкеты для возрастных групп 10–12, 13–15 и 16–17 лет, загрузка аватаров, лайки, личные сообщения, блокировки, жалобы и приватная очередь модерации PDF-доказательств.

## Запуск на Windows

1. Установи Node.js 20 или новее.
2. Распакуй архив в отдельную папку.
3. В PowerShell открой эту папку.
4. Создай `.env` из шаблона и задай два уникальных секрета:

```powershell
Copy-Item .env.example .env
$session = node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
$admin = node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
(Get-Content .env) -replace '^SESSION_SECRET=.*$', "SESSION_SECRET=$session" -replace '^ADMIN_TOKEN=.*$', "ADMIN_TOKEN=$admin" | Set-Content .env
```

Не публикуй содержимое `.env` и не отправляй секреты в чаты.

5. Установи зависимости и запусти сервер:

```powershell
npm.cmd install
npm.cmd start
```

6. Открой `http://localhost:3000`.

## Очередь модерации

Заголовок `X-Admin-Token` с секретом `ADMIN_TOKEN` даёт доступ к `GET /api/mod/reports`. Проверенные PDF доступны только через защищённый endpoint `/api/mod/reports/:id/evidence`. Статус жалобы меняется через `PATCH /api/mod/reports/:id` с JSON `{"status":"reviewed"}`, `{"status":"dismissed"}` или `{"status":"actioned"}`. При статусе `actioned` аккаунт, указанный в жалобе, отключается. Не публикуй список обвиняемых и не делай вывод о виновности автоматически.

## Важно перед запуском в интернет

Это локальный прототип, а не готовый публичный сервис. Перед публичным запуском нужны HTTPS, защита от CSRF для cookie-сессий (в текущей версии применяется Bearer-токен в localStorage), подтверждение возраста/родительские и правовые требования для конкретной страны, проверка изображений антивирусом, модераторская панель с MFA, аудит доступа, политика хранения/удаления данных, резервные копии и независимый security review. PDF не публикуются как статические файлы; они доступны только через административный маршрут. Доступ к локальному сайту не делает его доступным друзьям через интернет.
